# CS330

1. How do I approach designing software?
   Overall, this was a very large project. As with any large project, the best thing to do is to break it down into smaller parts. That's exactly what was done in this class. I started with a photo full of complex objects. The first task was to break those down into groups of more simple objects like boxes, cylinders, tapered cylinders, prisms, tori, halfspheres, and planes. This was the foundation for all the objects I had to build. All objects have the same pattern. You need to scale, rotate, translate, then either apply a color or a texture, and material. Applying this simple process to each complex object made the whole ordeal a bit simpler to tackle in my mind. This simple breakdown applies to almost every program. It also helps to realize natural modularity for simpler cleaner code.

2. How do I approach developing programs?
   I used several strategies when working on my scene. I took it one object at a time. This allowed me to focus on each object and get it correct and looking good before moving on. I ran the code often to materialize changes in near real time. I found that I had to do some things first before starting on the first object. I first had to add some lighting to be able to se the scene and then I had to add camera controls and movement to be able to move about the scene to see if my object placements are correct from all the angles as it may look good from the front but be way off from the top. This constant checking of position was needed throughout the process. I started off trying to picture the entire scene but by the end, I was taking it little chunk by chunk. this helped get me through the massive project.

3. How can computer science help me in reaching my goals?
   This project and course will be very useful in both my educational and professional pathways. I haven't done much work with graphics and lighting so this has helped to expand my skillset and help to understand 3d modeling with lighting. It helps to appreciate just how much goes into 3d games. It also gave me a refresher on some basic algebra, a bit of trigonometry and some geometry. Professionally, I can apply the process learning to almost any task given to me. Always break down big tasks into smaller more manageable ones. Iterate often and document meaningful results. Lastly, the visualization skills apply to many situations that can help with communication with coworkers.
